# CVStudio

CVStudio permet de créer et publier un CV interactif. Le code de l’application, sa documentation et ses commandes se trouvent dans [`site/`](site/README.md).

Le contenu de démonstration est fictif. Chaque installation conserve ses données dans sa propre base SQLite, hors de Git.
